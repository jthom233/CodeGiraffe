# Implementation Plan: Sigma.js Dashboard Migration

**Branch**: `013-sigma-dashboard` | **Date**: 2026-02-18 | **Spec**: [spec.md](spec.md)

## Summary

Replace the Code Giraffe dashboard renderer (Cytoscape.js → Sigma.js v3) to support interactive visualization of 30,000+ node architecture graphs. Add server-side ForceAtlas2 layout computation (optional dep, grid fallback) that runs once on init/sync and caches x,y coordinates in the stored graph. The dashboard renders pre-positioned nodes via WebGL, achieving ~2s load time at 33k nodes vs. the current browser hang.

## Technical Context

**Language/Version**: Python 3.11+ (server), Vanilla JS ES5-compatible (dashboard)
**Primary Dependencies**: sigma@3.0.2 + graphology@0.26.0 (CDN UMD); fa2 (optional Python)
**Storage**: Existing JSON/SQLite — layout dict added to GraphData
**Testing**: pytest; DASHBOARD_HTML string assertions (existing pattern)
**Target Platform**: Any WebGL-capable browser (Chrome, Firefox, Safari, Edge)
**Performance Goals**: 33k-node graph renders in ≤5s; pan/zoom <100ms
**Constraints**: No build toolchain; single embedded HTML string; optional layout dep
**Scale/Scope**: 33,880 nodes / 25,170 edges target; tested at 500–50,000 nodes

## Phase 0: Research — Complete

See `research.md`. All decisions resolved:
- **Renderer**: Sigma.js v3 (sigma@3.0.2) + graphology@0.26.0 via CDN UMD — 2 script tags, no build step
- **Layout**: ForceAtlas2 via `fa2` Python package (optional); deterministic grid fallback when absent
- **Storage**: `layout: dict[str, list[float]]` field on `GraphData` (Pydantic, default `{}`)
- **Shapes**: color-only differentiation; all nodes rendered as circles (Sigma default)
- **Edges**: color-only via `edgeReducer`; all edges solid lines

## Phase 1: Design — Complete

See `data-model.md` and `contracts/api-graph.md`.

Key contracts:
- `GET /api/graph` response nodes now include optional `x: float` and `y: float`
- `GraphData.layout` is a new optional field `dict[str, list[float]]`
- `to_d3_json()` emits `x`/`y` per node when `data.layout` has an entry for that node ID

## Complexity Tracking

| Addition | Why Needed | Simpler Alternative Rejected Because |
|---|---|---|
| Sigma.js v3 (WebGL) | Cytoscape.js hangs at 1,500+ nodes; 33k is target | No simpler CDN-loadable option renders 33k nodes at 30fps |
| ForceAtlas2 (optional) | cose layout is O(n²), unusable at 33k nodes | Grid fallback always available; fa2 is optional, not mandatory |
| `layout` field on GraphData | Pre-computed positions must survive server restarts | In-memory only: positions lost on every MCP server restart |
